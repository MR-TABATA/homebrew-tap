# mr-tabata/tap

Homebrew formulae for [MR-TABATA](https://github.com/MR-TABATA)'s tools.

```sh
brew install mr-tabata/tap/mrdiff
```

| formula | what it is |
| :--- | :--- |
| [`mrdiff`](https://github.com/MR-TABATA/MrDiff) | Images, binaries, URLs — and text, of course. One command, two answers: do they differ, and where. |

Formulae install prebuilt universal (Apple Silicon / Intel) binaries from each
project's GitHub Release, so there is nothing to compile.
